# RentnerDorf

**Play:** https://thomasfercher.github.io/rentnerdorf-play/

A single-player island-building game against 1–3 AI opponents, running in the browser.
It needs **WebGPU**: a recent Chrome, Edge or Safari (or another browser with WebGPU on) on a supported device.

This repository only hosts release builds. Each release is published here automatically and served by GitHub Pages.

Credits and licenses for the bundled 3D models and textures are in the game under Settings → Credits & licenses.
